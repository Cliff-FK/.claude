# Les interdits, et ce qu'ils coûtent

Table de relecture. Chaque ligne redit une règle du skill sous la forme sous laquelle on la voit
tomber, et dit le prix payé. À passer sur une page finie, sur un plan de corpus, ou sur un audit.

| interdit | conséquence |
|---|---|
| Calquer la structure du corpus sur celle du produit ou du code | le lecteur cherche par besoin, pas par module |
| Mélanger deux quadrants dans une page | le lecteur pressé et le lecteur curieux sont perdus tous les deux |
| Éditer une page générée depuis le code | écrasée à la prochaine génération |
| Titre portant le nom technique | introuvable par recherche, le lecteur ne le tape pas |
| Sommaire alphabétique ou dans l'ordre du code | le spécialisé passe avant le générique |
| Groupe rassemblant des natures différentes sous un mot vague | égare avant même l'ouverture d'une page |
| Rassembler les bases de l'hôte dans un dossier à part | oblige à l'aller-retour sur un même sujet |
| Référence par objet quand un élément traverse plusieurs objets | autant de copies que d'apparitions, qui divergent |
| Aucune explication pour ce qui met deux dépendances en jeu | le lecteur assemble à l'aveugle, chaque how-to ayant l'air complet |
| Reformuler un titre sans router l'ancienne ancre | des liens déjà envoyés cessent de fonctionner |
| Créer un dossier pour une seule page | un niveau de profondeur que le lecteur doit deviner |
| Affirmer un comportement non vérifié | une documentation fausse coûte plus cher qu'une absente |
| Recopier une explication d'une autre page | les deux copies divergent au premier changement |
| Limites et cas particuliers en tête de page | bloquent le lecteur qui n'y était pas exposé |
| Liste à puces sur un contenu qui a des liens logiques | les connecteurs disparaissent, le raisonnement devient un inventaire |
| Paragraphes d'une phrase enchaînés | le texte est haché, la hiérarchie des idées se perd |
| Supposer une convention de projet au lieu de la lire | le corpus se retrouve avec deux organisations concurrentes |
| Citer un texte produit ailleurs sans en garder l'empreinte | la page devient fausse sans que rien ne le signale |
| Lire la source à l'affichage plutôt qu'en amont | la doc dépend du système documenté et varie d'un lecteur à l'autre |
| Réclamer un identifiant dédié au produit pour la doc | le produit se met à dépendre de sa documentation |
| Expliquer le socle et une extension au fil du même texte | le lecteur ne peut pas voir laquelle des deux situations est la sienne |
| Ranger une page d'extension dans un groupe nommé d'après l'extension | le lecteur cherche par tâche, pas par origine du code |
| Tutoriel qui traverse plusieurs domaines, ou étape qui suppose une notion non posée | son titre ment sur ce qu'on y trouve |
| Titre dont le corps tient en une phrase | ce n'est pas une section, la phrase appartient au chapeau ou à la voisine |
| Recopier un commentaire de code comme un fait | il dit ce que quelqu'un croyait vrai le jour où il l'a écrit |
| Corriger la page sans relever les autres pages du même sujet | la voisine continue de dire l'ancienne version |
| Page illustrée dont le premier média montre ce que fait le sujet | le lecteur ne sait toujours pas où aller |
| Scène qui s'arrête à la porte, ou rangée de modes non cliqués | n'apprend rien de plus qu'une phrase |
| Écrire le balisage d'un média dans la page | la première retouche de mise en scène devient quarante retouches qui divergent |
| Juger la lisibilité d'une image à l'œil | le cadre réduit une image verticale par sa hauteur, le calcul le dit et l'œil non |
| Publier une capture d'écran réel sans neutraliser ses contenus | des données de client se retrouvent dans le manuel |
| Laisser une règle de forme mesurable en prose | elle se recasse à chaque passe, sans que rien ne le signale |
| Tirer une conclusion d'une sonde non étalonnée | elle fabrique le défaut qu'elle croit trouver |
| Citer un libellé de l'hôte, traduit à l'affichage | met une langue étrangère dans le manuel, et la citation devient invérifiable |
| Citer un texte qui contient du balisage | fait échouer la construction du corpus entier, et l'échapper romprait l'empreinte |
| Saisir une citation à la main ou depuis un rendu | les insécables et apostrophes typographiques se perdent, et l'écart n'avertit pas |
| Page qui ne déclare nulle part le sujet qu'elle documente | l'oracle de couverture est aveugle sur elle |
| Poser un renvoi ailleurs que dans une phrase de prose | il n'a rien à ouvrir et casse ce qui le porte |
| Reporter un seuil chiffré mesuré sur un autre corpus | la règle est portable, le nombre ne l'est pas |
